## 📌 Описание проекта

Данный проект представляет собой полнофункциональное веб-приложение, разработанное в рамках выполнения практических блоков **4–10** учебного пособия по курсу веб-разработки на Node.js.

В соответствии с заданием базовая тема из пособия («Три кота») была полностью заменена на индивидуальную тематику — **FlStudio** (популярная цифровая звуковая рабочая станция). 

В приложении реализован каталог легендарных инструментов и синтезаторов FL Studio:
* **Sytrus** — мощный гибридный синтезатор (FM, RM и субтрактивный синтез).
* **Harmor** — аддитивно-субтрактивный синтезатор с технологией ресинтеза.
* **Gross Beat** — инструмент тайм-манипуляций (глитч, скретч, сайдчейн).

Проект разделён на **29 изолированных веток Git** (`block-4.1` ... `block-10.8`), наглядно демонстрирующих поэтапную разработку каждого шага задания.

---

## 🛠 Технологический стек

* **Бэкенд:** Node.js, Express 4
* **База данных и ORM:** MongoDB, нативный драйвер `mongodb`, ORM `mongoose`
* **Шаблонизатор:** EJS + `ejs-locals` (мастер-лейауты, блоки)
* **Сессии и безопасность:** `express-session`, `connect-mongo` (хранение сессий в БД), модуль `crypto` (HMAC-SHA1 + соль для паролей)
* **Стили и интерфейс:** Bootstrap 5 (CDN)

## 🚀 Инструкция по установке и запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/7molly/AIP2026FL.git
cd AIP2026FL
```

Переключение на финальную версию (или любую интересующую ветку от `block-4.1` до `block-10.8`):
```bash
git checkout block-10.8
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск MongoDB
Убедитесь, что служба MongoDB запущена локально:
```bash
# macOS (Homebrew)
brew services start mongodb-community

# или напрямую демоном
mongod --config /opt/homebrew/etc/mongod.conf
```

### 4. Посев тестовых данных (сидирование)
Чтобы в базе появились плагины FlStudio:
```bash
node createDB.js
```

### 5. Запуск веб-сервера
```bash
npm start
```
Приложение будет доступно в браузере по адресу: [http://localhost:3000](http://localhost:3000)

## 🔍 Сценарий проверки функционала (в версии 29)

1. **Главная страница:** Откройте `http://localhost:3000`. Вы увидите приветствие неавторизованного пользователя и счётчик посещений страницы.
2. **Ограничение доступа:** Попробуйте перейти по ссылке на любой плагин (например, `/plugins/sytrus`). Сработает middleware `checkAuth` и перенаправит вас обратно на главную страницу с предложением войти.
3. **Регистрация / Вход:** Перейдите по ссылке «Войти» (`/logreg`), введите логин и пароль. Если такого пользователя нет, он автоматически создастся, а пароль будет захеширован с солью.
4. **Авторизованный режим:** После входа в шапке отобразится кнопка «Выйти (<ваш_логин>)», а страницы плагинов станут доступны для просмотра.
5. **Выход:** Нажмите кнопку «Выйти» — сессия очистится, а доступ к закрытым страницам снова заблокируется.
